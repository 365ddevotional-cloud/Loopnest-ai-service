Please carefully improve the existing “Post to YouTube” system in the 365 Daily Devotional SpiritTone song administration area.

IMPORTANT SAFETY RULES

1. Extend the existing YouTube publishing feature only.
2. Do not rebuild or refactor the music system.
3. Do not modify Church Mode, authentication, admin login, devotional content, donations, Android packaging, AAB generation, ADMIN_PASSWORD, AAB_DOWNLOAD_TOKEN, Google OAuth credentials, package name, signing keys, existing songs, audio files, MP4 files, statistics, testimonies, collections, or unrelated systems.
4. Preserve the working YouTube OAuth connection.
5. Create a checkpoint before making changes.
6. Do not publish or upload any real video while implementing or testing.
7. Do not deploy automatically.
8. Make the smallest compatible changes possible.

GOAL

Expand the existing “Post to YouTube” dialog so the administrator can schedule videos, provide or select a thumbnail, answer YouTube’s important publishing questions, and reuse saved editable defaults for future uploads.

PART A — YOUTUBE PUBLISHING DEFAULTS

Inside the existing Admin → Songs → YouTube Publishing section, add an admin-only settings area named:

“YouTube Publishing Defaults”

Allow the administrator to save editable default values for:

- Default privacy
- Default made-for-kids answer
- Default synthetic or altered-content answer
- Default video category
- Default language
- Default license
- Allow embedding
- Show public statistics
- Notify subscribers, when supported
- Default tags
- Default description footer
- Default playlist
- Default thumbnail choice
- Default scheduling timezone
- Default scheduling behavior
- Any other repeated YouTube field already supported by the existing integration

Use these initial ministry defaults:

- Privacy: Private
- Made for kids: No
- Contains realistic altered or synthetic content: No
- Category: Music
- Language: English
- License: Standard YouTube License
- Allow embedding: Yes
- Public statistics visible: Yes
- Notify subscribers: Yes, where supported
- Default thumbnail: Use the song’s existing cover artwork
- Scheduling timezone: America/Chicago
- Scheduling behavior: Publish immediately unless Schedule is selected

All saved defaults must remain editable.

Saving defaults must not change previously uploaded YouTube videos or existing song records.

Store these defaults using the project’s existing server-side database/configuration pattern. Do not store them only in localStorage.

Every field populated from defaults must remain editable for that particular upload.

PART C — SCHEDULING

When “Schedule for later” is selected:

1. Require a future date and time.
2. Display the administrator’s timezone clearly.
3. Convert the selected time correctly to the ISO 8601 value required by YouTube.
4. Upload the video with privacy set to Private.
5. Set YouTube’s scheduled publishAt value.
6. Inform the administrator:

   “YouTube requires scheduled videos to be uploaded as Private until the scheduled publication time.”

7. Reject past dates.
8. Display the final scheduled local date, time, and timezone in the confirmation dialog.
9. Save the schedule in the song’s YouTube publishing record.
10. Display:
   - Scheduled
   - Scheduled date/time
   - Processing
   - Published
   - Failed

Do not claim the video will become Public if YouTube’s API project restrictions prevent public publishing.

PART D — THUMBNAILS

1. If the song already has cover artwork, preselect it as the YouTube thumbnail.
2. Show a preview before publishing.
3. Allow the administrator to upload another JPEG or PNG thumbnail.
4. Validate the file before upload.
5. Maximum thumbnail file size: 2 MB.
6. Do not store image data directly in localStorage or database text fields.
7. Use the existing object-storage/upload mechanism and store only the URL.
8. After the YouTube video upload succeeds and returns a video ID, upload the chosen custom thumbnail using the official YouTube thumbnails.set API.
9. If the custom-thumbnail upload fails, do not mark the entire video upload as failed. Save the successful video and show a separate thumbnail warning.
10. Do not crop the thumbnail. Fit the full image into a 16:9 YouTube thumbnail canvas while preserving its aspect ratio.
11. Recommend 1280 × 720 in the interface.
