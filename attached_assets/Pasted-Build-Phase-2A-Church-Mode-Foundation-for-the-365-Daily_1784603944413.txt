==================================================
CRITICAL DESIGN DIRECTION — CHURCH MODE ENVIRONMENT
==================================================

Church Mode must not feel like another ordinary page inside 365 Daily Devotional.

When a user enters Church Mode, they should immediately feel that they have entered a distinct, refined church ministry environment.

The transition should be clear but graceful.

Church Mode must feel:

• Mature
• Beautiful
• Professional
• Trustworthy
• Peaceful
• Reverent
• Organized
• Suitable for pastors and established churches
• Appropriate for both small ministries and large congregations

Pastors should feel proud and confident using it with their members.

Do not make it childish, flashy, crowded, overly colorful, or similar to a social-media entertainment app.

Do not use cartoon church illustrations, excessive animations, bright rainbow colors, oversized decorative icons, or cheap-looking gradients.

--------------------------------------------------
CHURCH MODE VISUAL IDENTITY
--------------------------------------------------

Create a dedicated Church Mode visual shell that is different from the normal 365 Daily Devotional environment.

Use a sophisticated church-oriented palette such as:

Primary:
• Deep navy
• Midnight blue
• Deep burgundy
• Rich charcoal

Supporting colors:
• Warm ivory
• Soft cream
• Muted gold
• Subtle bronze
• Gentle stone gray

Accent colors should be used carefully.

Avoid excessive gold, excessive darkness, or low-contrast text.

The final design must remain highly readable in daylight and on mobile devices.

Suggested visual character:

• Deep navy or refined burgundy header
• Warm ivory or soft cream page background
• Muted gold accents for selected items, dividers, and important actions
• Clean white or cream content cards
• Soft shadows
• Refined borders
• Generous spacing
• Strong but elegant typography
• Restrained ministry-related visual details

A very subtle background texture or pattern may be used, such as:

• Faint architectural lines
• Subtle stained-glass-inspired geometry
• Very faint cross pattern
• Soft sanctuary-light effect

Any pattern must remain subtle and must never interfere with readability.

Do not use a photograph as the general background.

--------------------------------------------------
CHURCH MODE HEADER
--------------------------------------------------

Create a dedicated Church Mode header.

It should include:

• Church Mode title or the current church name
• Church logo when available
• Professional default church emblem when no logo exists
• Clear way to return to the main 365 Daily Devotional environment
• User role where appropriate, such as:
  - Church Owner
  - Lead Pastor
  - Administrator
  - Ministry Leader
  - Member

The header should make it clear that the user is now inside their church space.

Possible small label:

“Church Mode”

Possible supporting phrase:

“A dedicated space for your church community”

Do not make the header unnecessarily tall.

On mobile, keep it clean, compact, and easy to navigate.

--------------------------------------------------
CHURCH MODE NAVIGATION
--------------------------------------------------

Church Mode should have its own internal navigation.

Do not place every future Church Mode feature in the main 365 hamburger menu.

For Phase 2A, the Church Mode navigation should include only features that actually exist:

• Church Home
• Members
• Join or Invitation Tools
• Church Administration — authorized roles only
• Return to 365 Daily Devotional

Do not show empty navigation links for features that have not been built.

Later Church Mode features such as sermons, bulletins, giving, and church communication will be added inside this dedicated environment rather than making the main app menu longer.

--------------------------------------------------
VISUAL CONSISTENCY
--------------------------------------------------

Church Mode must feel distinct, but it should still belong to the 365 Daily Devotional family.

Retain:

• Existing accessibility standards
• Familiar button behavior
• Existing account identity
• Existing authentication
• Existing toast and modal behavior where suitable
• Existing font family unless a compatible existing font creates a more refined Church Mode appearance

Do not load a large new font package merely for Church Mode.

Use typography, spacing, color, borders, and layout to create the different atmosphere.

Do not globally change the colors of the existing 365 Daily Devotional pages.

The special visual theme applies only while the user is inside Church Mode.

ORGANIZE THE EXISTING HAMBURGER MENU
==================================================

CURRENT PROBLEM:

The existing hamburger menu has become too long because many destinations are displayed in one continuous list.

Reorganize the existing hamburger menu into mature, clearly labeled collapsible groups.

This change is for organization only.

Do not:

• Delete any existing menu destination
• Break any route
• Change permissions
• Change the function of any page
• Create duplicate links
• Rename the actual routes
• Modify the pages linked from the menu
• Add unfinished features

Use an accordion-style menu.

When the hamburger menu first opens:

• Show the major group names.
• Allow the user to tap a group to expand its links.
• Allow the group to collapse again.
• Keep the menu short and uncluttered.
• Use clear chevron indicators.
• Use smooth, restrained expansion.
• Do not use excessive animation.
• Only one group may remain open at a time on small screens if that provides a cleaner experience.
• Highlight the group containing the current page.
• Keep the current page visibly selected.

Important high-frequency destinations may remain immediately visible above the groups only when truly necessary, such as:

• Home
• Today’s Devotional
• Church Mode

Do not keep many ungrouped links above the accordion.
