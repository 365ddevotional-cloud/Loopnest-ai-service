PART 1 — REDESIGN CHURCH MODE
==================================================

CURRENT PROBLEMS

The current Church Mode interface:

• Is too dark.
• Uses small and faint text.
• Has low-contrast gray wording.
• Makes members strain their eyes.
• Uses oversized dark blocks with too much empty space.
• Has a strong grid background that competes with the content.
• Does not look polished enough for pastors and established churches.
• Has icons or text that almost disappear against dark cards.
• Does not create a beautiful, realistic church-community experience.

Redesign the complete Church Mode visual system.

--------------------------------------------------
DESIGN DIRECTION
--------------------------------------------------

Church Mode must feel like a refined digital church environment.

It should feel:

• Mature
• Beautiful
• Warm
• Reverent
• Professional
• Trustworthy
• Modern
• Organized
• Peaceful
• Suitable for small and large churches

Do not make it childish, flashy, or similar to a social-media entertainment app.

Use a brighter and more balanced palette.

Recommended palette:

• Warm ivory page background
• Soft cream content sections
• White cards where appropriate
• Deep navy used mainly for the header, footer, and selected emphasis
• Rich burgundy or warm rust for important headings
• Muted gold for accents and selected states
• Charcoal or deep brown for body text
• Soft gray only for secondary information

Do not cover the entire screen with navy cards.

Use dark cards only where they create useful contrast.

The present gold grid background is too visually strong. Replace it with one of these:

• A very faint architectural pattern
• A soft church-window-inspired geometric pattern
• A subtle paper or linen texture
• A nearly invisible grid with much lower opacity

The background must never cross through text strongly or make the content difficult to read.

--------------------------------------------------
TYPOGRAPHY
--------------------------------------------------

Use the large, strong, highly readable style shown in the reference screenshot with bold ChatGPT-like lettering.

Use the existing app font where possible, but make the visual hierarchy resemble a modern, highly readable interface.

Preferred typography behavior:

• Body and interface text: clean system sans-serif, Inter, or the existing equivalent
• Church names and major ministry headings: refined bold serif or the existing Church Mode display font
• Avoid thin font weights
• Avoid pale gray text on cream
• Avoid tiny labels

Minimum mobile sizes:

• Church name on Church Home: 32–38px, bold
• Main page headings: 30–36px, bold
• Section headings: 24–28px, bold
• Card titles: 21–24px, bold
• Navigation labels: at least 17–18px, semibold
• Body text: at least 18px
• Form labels: at least 17px, semibold
• Inputs: at least 18px
• Helper text: at least 16px
• Buttons: at least 18px, bold
• Metadata: never below 15px

Use responsive scaling where appropriate, but do not allow mobile text to become tiny.

All primary text must pass strong contrast requirements.

--------------------------------------------------
CHURCH HEADER

Make the church identity prominent.

The header should clearly display:

• Church logo or professional placeholder
• Church name in large bold lettering
• Church Mode badge

• Return to 365 Daily Devotional button

The church name must be visually dominant.

Do not allow the church name to appear small or secondary.

On mobile:

• Keep the header compact but readable.
• Allow text to wrap safely.
• Do not squeeze the church name beside oversized controls.
• Keep the Return to 365 button usable without dominating the screen.
