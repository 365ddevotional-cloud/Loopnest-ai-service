Use a stale-while-revalidate strategy for song thumbnails:
- Show the cached thumbnail immediately when available.
- Check for an updated thumbnail quietly in the background.
- Replace the cached copy only when a newer successful response is received.
- Never replace a valid cached image with an error response.

- Show the last successfully loaded song list.
- Show the cached title, artist, description, release information, and thumbnail.

4. LAZY LOADING
Add:
loading="lazy"
decoding="async"

to song thumbnail images where appropriate.

Use an IntersectionObserver if needed so thumbnails farther down the page are loaded only when the user scrolls near them.

5. IMAGE PLACEHOLDER
If a song thumbnail has never loaded or is unavailable:
- Keep the existing professional placeholder.
- Do not repeatedly request a broken thumbnail on every render.
- When the network returns, retry the image once and cache it after success.

Use a clear cache version such as:

- Delete only old SpiritTone music cache versions.
- Do not delete unrelated app caches.

When the page is reopened:
- Display cached thumbnails and music data immediately.
- Then refresh quietly in the background when internet is available.
- Avoid forcing the user to wait for all thumbnails before displaying the page.

8. STORAGE SAFETY

- Do not cache passwords, authentication tokens, donation information, or sensitive user data.
